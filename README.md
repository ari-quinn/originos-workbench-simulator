# OriginOS 7 Workbench Simulator

An unofficial, experimental web simulation recreating the window management, interruptible animation curves, and 3D miniature rail transitions inspired by OriginOS.

This repository is an independent study created solely for educational and front-end experimentation purposes. It is not affiliated with, authorized, or endorsed by vivo Communication Technology Co., Ltd. OriginOS and related brand assets belong to their respective copyright holders.

## Overview

- Pure HTML5, CSS3, and vanilla JavaScript without external animation frameworks.
- Continuous C2 smooth, non-spring interruptible and parallel window transition physics.
- Shared single-vanishing-point 3D miniature rail and top-bar layouts.
- Traced OriginOS 7 system elements.

## Running Locally

Open `index.html` directly in any modern browser, or run a local static server:

```bash
python -m http.server 8000
```
